# Manjala Pavani — Portfolio

React + Vite portfolio with Framer Motion and Lucide icons.

## Run locally

1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Run:
   npm install
   npm run dev
4. Open the local URL shown by Vite.

## Before publishing

Edit `src/data.js`:
- Add your real LinkedIn, GitHub, Instagram and YouTube URLs.
- Add your real email in `src/App.jsx` where `YOUR_EMAIL@example.com` appears.
- Replace/add exact internship names if desired.
- Update project statuses and tags as projects progress.

Your uploaded profile photo is already included at:
`public/images/profile.jpg`
